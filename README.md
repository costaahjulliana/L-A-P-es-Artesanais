# LeA Pães Artesanais — landing page

## Como visualizar
Abra `index.html` no navegador. Para desenvolvimento local, você também pode usar a extensão Live Server no VS Code.

## Antes de publicar
1. Em `script.js`, altere `WHATSAPP_NUMBER` para o número comercial real, no formato internacional só com números (ex.: `5511999999999`).
2. Edite o array `products` em `script.js`: nome, categoria (`classicos`, `especiais` ou `doces`), tag, descrição, preço e imagem.
3. Os preços e produtos incluídos são exemplos demonstrativos, não dados oficiais da marca.
4. A foto enviada foi colocada em `assets/lea-referencia.png` como referência visual. Substitua por fotos reais dos produtos quando disponíveis.
5. As fotos de exemplo do catálogo usam URLs externas do Unsplash e precisam de internet para carregar.

## Estrutura
- `index.html`: estrutura da página
- `style.css`: visual e responsividade
- `script.js`: catálogo, filtros, busca e links de pedido
- `assets/lea-referencia.png`: imagem de referência enviada
